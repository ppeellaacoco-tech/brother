# Carta digital para mi hermano ❤️

## Archivos
- index.html → estructura
- style.css → diseño y animaciones
- script.js → interacción, texto y reproducción de YouTube
- database.sql → ejemplo de tabla MySQL
- IMG_2889.jpeg → foto usada en la carta

## Probarla
Abrí `index.html` en un navegador.

La canción usada es:
https://www.youtube.com/watch?v=YxIiPLVR6NA

Es "Hey Brother" de Avicii. La reproducción de YouTube puede depender de las políticas del navegador/dispositivo; el botón de la carta inicia la carga del reproductor.

## Importante sobre MySQL
El archivo SQL deja preparada la base de datos, pero esta versión es una página estática. Para que la página lea/escriba realmente en MySQL hace falta un backend (por ejemplo PHP o Node.js).
